# 찬양이 좋아서 모인 청년들 - LIVE WORSHIP 2026

향상교회와 더향상교회의 중고등부·청년이 함께 드리는 **청년 연합 라이브 워십** 안내 사이트입니다.
포스터와 공유 링크의 QR로 들어와 휴대폰 한 손으로 보는 것을 기준으로 만들었습니다.

- **사이트**: https://choiwk.github.io/Worship_Concert/
- **일시**: 2026년 12월 19일 토요일 저녁 7:30 ~ 9:00
- **장소**: 향상교회 3층 체육관 (경기 용인시 기흥구 언동로 140)
- **무대**: 찬양팀과 회중이 둥글게 둘러앉는 원형 무대 ([3D로 둘러보기](https://choiwk.github.io/worship-venue-3d/))

> 빌드 도구 없는 정적 HTML · CSS · JavaScript. 외부 라이브러리 없이 GitHub Pages 로 배포합니다.

## 화면 구성

아래 탭바의 다섯 화면은 해시 주소로 나뉩니다. 주소를 그대로 공유할 수 있고 뒤로가기도 동작합니다.

| 주소 | 화면 | 내용 |
|---|---|---|
| `#/main` | 메인 | 화면을 꽉 채운 배경 영상 위로 네 장면이 바뀝니다. 제목 → 일시·장소·참여하기 → 무대 이야기 → 말씀 |
| `#/songs` | 곡 리스트 | 예배 순서대로 묶은 12곡 카드, 콘티 이야기, 곡 전체 듣기 |
| `#/songs/11` | 곡 상세 | 가사, 함께 묵상할 말씀, 유튜브, 이전·다음 곡 |
| `#/word` | 말씀 나눔 | 팀원끼리 매주 묵상을 나누는 공간 (팀 암호), 모두에게 열어 둔 묵상 |
| `#/artists` | 멤버 소개 | 6개 팀, 17명. 카드를 누르면 그 사람의 한마디와 말씀 |
| `#/story` | 팀 소개 | 왜 모였는지에 대한 사진 이야기, 읽은 만큼 차오르는 진행 바, 후원하기 |

### 화면별 주요 동작

- **메인**
  - 「우리가 서로 사랑하자!」가 펜으로 쓰듯 왼쪽부터 나타납니다.
  - D-day 와 참여하기 버튼이 있습니다.
  - 「왜 원형일까요?」 팝업에서 원형 무대의 이야기를 읽을 수 있습니다.
- **곡 리스트·곡 상세**
  - 가사 글자 크기를 보통·크게로 바꿀 수 있고, 그 기기에 기억됩니다.
  - 가사를 내리면 위의 돌아가기 단추가 지금 곡 제목으로 바뀌고, 읽은 만큼 얇은 선이 찹니다.
  - 「말씀 보기」를 누르면 그 곡과 함께 묵상할 짧은 구절이 팝업으로 열립니다.
- **참여하기**
  - 이름·소속 교회·남길 이야기를 받아 바로 저장합니다.
  - 같은 기기에서 연속으로 누르는 것은 30초 동안 막습니다.
- **말씀 나눔**
  - 팀 암호를 넣은 기기만 목록을 읽고 쓸 수 있습니다.
  - 주차별·사람별로 볼 수 있고, 공개로 올린 글은 암호 없이 가로 카드로 보입니다.
- **공통**
  - 위쪽 막대를 누르면 배경음악을 켜고 끌 수 있습니다.
  - 아래 공유 버튼으로 카카오톡·인스타그램 DM·링크 복사를 할 수 있습니다.
  - 홈 화면에 추가하면 앱처럼 열립니다(PWA).

## 기술 구성

### 프런트엔드

| 항목 | 내용 |
|---|---|
| 구조 | `index.html` 한 장 안에 모든 화면을 두고, `html.on-<화면>` 클래스와 해시 라우팅으로 전환 |
| 스타일 | `src/css/style.css` 한 파일. CSS 변수(종이·잉크·테라코타 색), `clamp()`, Grid/Flex, `backdrop-filter` |
| 스크립트 | ES2015+ 일반 스크립트(`defer`). 모듈·번들러 없음 |
| 서체 | 나눔손글씨 「사랑해 아들」 한 가지. 사이트에 쓰인 글자만 담은 서브셋을 먼저 받고, 없는 글자가 나올 때만 전체 글꼴을 받습니다 |
| 애니메이션 | IntersectionObserver 등장 효과, CSS 마스크 손글씨 효과. `prefers-reduced-motion` 이면 모두 끕니다 |
| 접근성 | 팝업 포커스 이동과 ESC 닫기, `aria-*` 상태, 44px 이상 터치 영역, 본문 대비 4.5:1 |

### 메인 배경 영상

망 상태에 따라 세 단계 중에서 고릅니다.

| 단계 | 파일 | 언제 |
|---|---|---|
| 고화질 | `main-portrait.mp4` (약 4MB) | 기본 |
| 가벼운 것 | `main-portrait-light.mp4` (약 1MB) | 느린 망 |
| 사진만 | `main-portrait-poster.jpg` | 데이터 절약 모드·매우 느린 망 |

- 첫 화면에는 사진을 먼저 깔고, 영상이 실제로 재생되기 시작한 뒤에 서서히 겹칩니다.
- 영상이 정해진 시간 안에 시작하지 않거나 끊기면 한 단계씩 낮춥니다.
- 데이터 절약 모드일 때만 「영상 보기」 버튼이 나옵니다.

### 오프라인·캐시 (`sw.js`)

- 처음 들어올 때 페이지·스타일·스크립트·서체·팀 소개 사진을 미리 받아 둡니다.
- 페이지(HTML)는 네트워크를 먼저 쓰고, 끊기면 캐시를 씁니다.
- 나머지 파일은 캐시를 먼저 씁니다.
- 영상과 음원은 미리 받지 않고, 실제로 재생할 때 캐시에 담습니다.
- 참여 신청 같은 POST 요청과 바깥 주소로 가는 요청에는 손대지 않습니다.

### 서버 쪽 (Supabase)

서버 없는 정적 사이트라 저장이 필요한 두 기능만 Supabase 를 씁니다.

```
참여하기    브라우저 ──(공개 키, 넣기만 허용)──────────────▶ rsvp 표
말씀 나눔   브라우저 ──(팀 암호 + 글)──▶ Edge Function ──▶ devotion 표
                                    devotions
                                    (암호 확인)
```

- **참여 신청**: 공개(anon) 키에는 행 정책(RLS)으로 「넣기」만 허락합니다. 신청 목록은 사이트에서 읽을 수 없습니다.
- **말씀 나눔**: 표에는 공개 키로 접근할 수 없습니다.
  - 읽기·쓰기는 모두 Edge Function `devotions`(`supabase/functions/devotions/`)를 거칩니다.
  - 이 함수가 팀 암호를 확인한 뒤에만 표에 손댑니다.
  - 팀 암호와 서비스 키는 Supabase 의 Secrets 에만 있고, 이 저장소에는 없습니다.
- 처음부터 연결하는 방법: [`docs/참여신청-supabase-설정.md`](docs/참여신청-supabase-설정.md), [`docs/말씀나눔-supabase-설정.md`](docs/말씀나눔-supabase-설정.md)

### 배포

`main` 브랜치에 푸시하면 GitHub Actions 가 GitHub Pages 로 배포합니다.

## 내용 고치기

### 곡

[`src/js/songs.js`](src/js/songs.js) 의 `SONGS` 배열 한 곳만 고치면 곡 리스트와 곡 상세가 함께 바뀝니다.

| 필드 | 뜻 |
|---|---|
| `no`, `noEnd` | 곡 번호. 이어 부르는 두 곡은 `no: '06', noEnd: '07'` 처럼 한 카드로 묶습니다 |
| `slug` | 주소 조각 (`#/songs/06`) |
| `tag` | `'주제곡'` 이면 배지가 붙습니다 |
| `section` | 예배 순서 묶음 (`SETLIST_SECTIONS` 의 키: 여는 찬양, 예배, 말씀, 기도, 셀러브레이션, 파송) |
| `youtube` | 없으면 유튜브 버튼을 그리지 않습니다 |
| `parts` | 가사 묶음 `{ label, lyrics, bible }`. 이어 부르는 곡은 두 개 |

### 멤버

[`src/js/members.js`](src/js/members.js) 는 두 층입니다.

- 사람 정보는 `PEOPLE` 에 한 번만 적습니다.
- 팀 목록 `MEMBERS` 에서는 id 로 가리키기만 합니다.
- 그래서 여러 팀에 속한 사람도 한 곳만 고치면 됩니다.

```js
const PEOPLE = {
  'kim-yeeun': {
    name: '김예은', icon: '🤝', church: '더향상교회',
    photo: 'public/images/members/kim-yeeun.jpg',   // 없으면 이름 첫 글자
    instagram: 'https://www.instagram.com/아이디',
    bio: '한마디',
    verse: { text: '말씀 본문', ref: '사도행전 20장 24절' }
  }
};
const MEMBERS = [
  { group: '악기팀', people: [{ id: 'choi-wonkeun', role: '드럼' }] }
];
```

- 카드 아래 줄에는 파트(`role`)가 있으면 파트를, 없으면 소속 교회를 보여 줍니다.
- `instagram`·`bio`·`verse` 중 하나라도 있으면 카드 테두리가 빛나고, 누르면 아래에서 소개 시트가 올라옵니다.
- 인스타 사진은 자동으로 가져올 수 없어 한 번 내려받아 `public/images/members/` 에 둡니다.
- 개인 계정을 공개 페이지에 거는 것이므로 본인 동의를 받고 넣습니다.

### 일시·장소

[`src/js/app.js`](src/js/app.js) 의 `CONCERT` 객체 한 곳에 있습니다. D-day 와 메인 일시·장소, 팀 소개 마지막 문구가 이 값을 읽습니다.

`index.html` 의 메타 태그·구조화 데이터와 `manifest.json` 설명문은 함께 손으로 고쳐야 합니다.

### 고친 뒤 꼭 할 일

1. **캐시 번호 올리기**
   - `index.html`·`sw.js`·`style.css` 의 `?v=N` 을 모두 같은 번호로 올립니다.
   - `sw.js` 의 `CACHE_NAME` 도 같은 번호로 올립니다.
   - 그래야 이미 방문한 휴대폰도 새 버전을 받습니다.
2. **새 글자 확인**
   - 화면에 새 글자를 넣었다면 손글씨 서브셋에 그 글자가 있는지 확인합니다.
   - 없으면 [`public/fonts/README.md`](public/fonts/README.md) 대로 서브셋을 다시 만듭니다.

## 로컬에서 보기
